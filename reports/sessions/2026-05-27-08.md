## What landed

### Ack-edit -> calibration label
- `wlog ack`, `wlog ack --edit`, and `wlog ack --reject` now write
  `task_edits` rows for every changed field (`title`, `body`,
  `status`). Best-effort: ack still succeeds if the edit log write
  fails so the calibration loop never breaks the user-facing flow.

### Search via pgvector cosine
- `TaskRepo::find_similar(workspace_id, query_vec, limit)` shipped:
  pgvector cosine distance with the HNSW index, returns
  `(TaskNode, distance)` tuples.
- `TaskRepo::set_embedding(id, vec)` for the upcoming embed worker.
- `wlog search` picks the OpenAI embed path when `OPENAI_API_KEY` is
  set, falls back to substring otherwise.

### `wlog-web` crate (Phase 4)
- New workspace member with a single `wlog-web` binary.
- Axum routes: `GET /health`, `GET /workspaces`,
  `GET /workspaces/:slug/tasks` with `?status= &repo= &limit=`,
  `GET /workspaces/:slug/tasks/:id`.
- Healthcheck issues `SELECT 1` against the configured Postgres pool.

### Hetzner infrastructure
- `infra/hetzner/cloud-init.yml`: Debian 12 first-boot (Docker,
  ufw, fail2ban, ssh on port 2222, `wlog` user, bind mount layout).
- `infra/hetzner/Dockerfile`: multi-stage build emitting both
  `wlog` and `wlog-web` in one slim image.
- `infra/hetzner/compose.prod.yml`: Postgres + NATS + daemon + web +
  Caddy with pinned digests, secrets via `docker secret`, bind mounts
  under `/home/wlog/state`.
- `infra/caddy/Caddyfile`: reverse proxy for `/github-webhook`,
  `/api/*`, and `/healthz`.
- `infra/hetzner/README.md`: full bootstrap, secrets, backups, and
  monitoring runbook.
