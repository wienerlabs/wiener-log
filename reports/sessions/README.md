# Session reports

End-of-session reports per the operating mandate, §9.1. One file per session
named `YYYY-MM-DD-NN.md` where `NN` is the session ordinal for that day.

## Template

```markdown
# Session YYYY-MM-DD #N

- **Started**: HH:MM TZ
- **Ended**: HH:MM TZ
- **Phase**: <current>
- **Issues addressed**: #X, #Y, #Z
- **PRs opened**: !A, !B
- **PRs merged**: !C
- **ADRs created**: NNNN
- **LLM cost**: $X.XX (cumulative phase: $Y.YY)
- **Blockers**: <none | description>
- **Tomorrow**: <next planned tasks>

## Notes

Free-form observations, decisions made, surprises.
```
