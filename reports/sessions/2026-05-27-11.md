### Web HTML dashboard

`crates/wlog-web/src/lib.rs` grew from a JSON-only Axum stub to a
fully rendered HTML dashboard:

- `GET /` lists every workspace with a clickable table.
- `GET /w/:slug` shows status counts as five tiles + paginated
  task list + recent-10-event subjects panel.
- `GET /w/:slug/t/:id` shows a single task with pill, metadata
  block, body in a `<pre>`, and incoming/outgoing edge counts.
- `GET /static/style.css` serves the embedded stylesheet.
- All HTML uses the same `--cream` / `--ink` / `--dim` palette as
  the CLI brand. No JS. Status pills get semantic background tints
  (proposed gray, acked green, in-progress cyan, done deep green,
  rejected red).
- Existing JSON API at `/health`, `/workspaces`,
  `/workspaces/:slug/tasks`, `/workspaces/:slug/tasks/:id`
  preserved alongside the new HTML routes.

### `wlog admin cost`

Cross-cut rollup of the local cost ledger:

- per-purpose totals (`synthesis`, `triage`, `embedding`)
- per-day breakdown with row counts
- per-model breakdown with input/output/cache-creation/cache-read
  token counts

Sits next to the existing `wlog cost` (which is per-day +
per-model only).

### `wlog export`

Streams tasks to stdout in JSON (pretty) or CSV. Honors
`--status` and `--repo` filters and a `--limit`. Designed for
piping into `jq`, `csvkit`, or external reporting tools without
a separate database snapshot.

CSV header:
`id,status,node_type,title,repo,owner,created_at,updated_at`
with proper RFC 4180 quoting.
