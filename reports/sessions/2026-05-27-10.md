- `Status::{Ok, Fail, Warn, Info, Neutral}` enum with ✓ ✗ ⚠ ℹ ·
  glyphs and `[ok]` / `[fail]` / `[warn]` / `[info]` / `[--]`

  `hint`, `warning`, `success` helpers.

  bold headers and dynamic content arrangement.

- AtomicI8 `set_color_override` + `set_quiet` for runtime toggles.
- 9 unit tests covering symbol fallback, color override, redaction.

### New subcommands

| Command | Purpose |
| --- | --- |
| `wlog where` | Tabular summary of binary, config, cache, data, socket, CC projects, NATS+DB URLs (redacted). |
| `wlog about` | Build version, target triple, license, repo, family. |
| `wlog doctor [--offline]` | Identity + components (delegates to status) + docker container scan + footer. |
| `wlog log [--limit] [--kind] [--all-workspaces]` | Recent events from Postgres, comfy-table, optional substring kind filter. |
| `wlog tree <id> [--depth]` | ASCII DAG walker with Unicode box drawing, cycle detection, depth cap, per-status glyphs. |
| `wlog admin replay [--workspace] [--limit] [--dry-run]` | Re-publishes historic events from Postgres back to NATS via ADR-0007 subjects. |
| `wlog setup` | Interactive first-run wizard prompting for slug + name + handle + database URL, then delegating to `init`. |

### Refactored output

- `wlog status` uses ui::line + Status::Ok/Fail/Warn/Neutral
  symbols. `format_dur` renders round-trip latency.
- `wlog init` success now prints a brand banner + section +
  kv pairs + next-step arrows.
- `wlog admin users` / `workspaces` use boxed comfy-table with
  bold headers and dim row counter.
- `wlog admin tail` prints a header + dim timestamp + cyan
  subject, shows interrupt count on Ctrl-C.

### Global flags

- `--quiet` / `-q` / `WLOG_QUIET=1` suppresses informational
  output (errors still print to stderr).
- `--no-color` / `NO_COLOR=1` disables ANSI globally.
- Both plumb through `ui::set_color_override` + `ui::set_quiet`
  AtomicI8 instead of mutating env vars (no `unsafe` blocks).

### Governance

  palette, semantic Status enum, helper conventions, comfy-table
  decision, behavioral contract for NO_COLOR / WLOG_COLOR / TTY.

  `status` / `where` / `about` / `doctor` are split instead of
  flag-overloaded, exit code conventions, redaction policy,
  `--offline` mode.

  in the message body. Project-wide rule enforced at the hook
  layer.
