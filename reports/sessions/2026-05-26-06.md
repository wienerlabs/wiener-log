## What landed

### GH webhook receiver (#29, closed)

- `wlog-ingest-gh` split into clean modules:
  - `event.rs`: `GhEvent` + `GhEventKind` with `subject_suffix()`
    returning `pr.opened`, `workflow.completed`, `push`, etc.
  - `hmac.rs`: constant-time HMAC-SHA256 verifier + signing helper
    for tests.
  - `replay.rs`: bounded LRU dedup keyed on `X-GitHub-Delivery`.
  - `router.rs`: Axum router with one `POST /webhook` route,
    HMAC + replay + parse + sink-dispatch in that order.
- 13 unit tests cover HMAC round-trip, replay eviction, router
  acceptance / 202 for unknown kinds / 401 for bad signature /
  duplicate-drop.
- Daemon spawns the receiver alongside the socket listener:
  - `DaemonConfig.gh_listen` + `gh_secret` flags.
  - `GhSinkAdapter` bridges `wlog-ingest-gh::EventSink` into the
    existing `PayloadSink` so the wire path stays uniform.
  - `NatsSink::accept_gh` publishes
    `wlog.{workspace}.event.gh.{subject_suffix}` per ADR-0007.
- `crates/wlog-cli/tests/gh_e2e.rs`: testcontainers NATS, free-port
  daemon, reqwest-signed POST, assert subject + parsed body.

### Engine NATS consumer (#30, closed)

- `wlog-engine::consumer`:
  - `get_or_create_stream(WLOG_EVENTS)` with subjects
    `wlog.*.event.>`, file storage, 30-day retention.
  - Durable pull consumer `engine-consumer-default` with explicit ack
    policy.
  - `WorkspaceCache` resolves slug -> `WorkspaceId` once per slug.
  - `ParsedSubject` decomposes `wlog.{ws}.event.{source}.{kind...}`
    and supports compound kinds like `gh.pr.opened`.
  - Each message persists via `EventRepo` then acks; persist failures
    leave the message un-acked for redelivery.
- 3 subject-parsing unit tests.

## Decisions made

- **`PayloadSink::accept_gh` carries the suffix separately** so the
  daemon can pre-compute the subject leaf without re-parsing inside
  `NatsSink`. Lower coupling between the GH parser and the NATS
  publisher.
- **`GhSinkAdapter` lives in the daemon**, not the GH library. Keeps
  `wlog-ingest-gh` free of NATS or `PayloadSink` knowledge so future
  receivers (Slack, Linear) can reuse the router pattern.
- **MockEmbedder is deterministic**, not random. Tests assert exact
  vectors when they need to; non-asserting tests still consume
  predictable shapes.
- **Subject parser handles compound kinds** like `gh.pr.opened`
  through `iter.collect::<Vec<_>>().join(".")`. Keeps ADR-0007's
  hierarchy intact without dotted-keyword reservations.
- **Allow `duration_suboptimal_units` at workspace level** instead of
  scattering per-call attributes. One justification comment beats
  twelve attribute lines.
