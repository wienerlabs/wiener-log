### Monitoring stack
- `infra/monitor/compose.monitor.yml`: Grafana 11.4.0 +
  Loki 3.3.2 + Promtail 3.3.2 + Prometheus 2.55.1, layered on
  top of `compose.prod.yml` via the external `wlog-prod_default`
  network. Bind mounts under `/home/wlog/state/{prometheus,loki,
  grafana}`.
- `infra/monitor/prometheus.yml`: scrapes daemon (9789), web
  (8088), NATS metrics (8222), cadvisor, node-exporter at 15s.
- `infra/monitor/loki.yml`: TSDB v13 schema, 720h retention,
  filesystem backend, compactor with retention enabled.
- `infra/monitor/promtail.yml`: Docker SD with JSON pipeline
  stage (level, target, timestamp).
- `infra/monitor/grafana/`: pre-provisioned Prometheus + Loki
  datasources and the `WienerLog Overview` dashboard
  (socket / CC / GH event rates, LLM USD today, synthesis p95,
  daemon logs, tasks by status, calibration MAPE).
- `infra/monitor/README.md`: apply + secret + Caddy patch
  instructions.

### systemd units (Hetzner)
- `infra/systemd/wlog-daemon.service`: Type=simple,
  EnvironmentFile=/home/wlog/state/{daemon.env,version.env},
  ExecStartPre pulls the pinned image, ExecStart runs the
  prod compose stack with the monitor overlay. Security
  hardening: NoNewPrivileges, ProtectSystem=strict,
  PrivateTmp, RestrictAddressFamilies, RestrictNamespaces.
- `infra/systemd/wlog-backup.{service,timer}`: 03:23 UTC nightly,
  RandomizedDelaySec=600, runs `scripts/backup-postgres.sh`.
- `infra/systemd/wlog-healthcheck.{service,timer}`: every 5min
  starting 2min after boot, runs `scripts/healthcheck-ping.sh`.
- `infra/systemd/README.md`: bootstrap + required env file
  documentation.

### macOS launchd plist
- `infra/macos/io.wienerlabs.wlog-daemon.plist`: local-only
  `wlog daemon` install for developer machines, with
  RunAtLoad + KeepAlive, log paths under `~/Library/Logs`.
- `infra/macos/README.md`: bootstrap + bootout instructions.

### Ops scripts
- `scripts/backup-postgres.sh` (executable): `pg_dump --no-owner
  --no-privileges --format=plain` from the `wlog-postgres`
  container, gzipped with atomic `.tmp` + `mv`, retention via
  `find -mtime`, optional `HEALTHCHECKS_BACKUP_URL` ping.
- `scripts/healthcheck-ping.sh` (executable): probes
  `WLOG_PING_TARGET`, posts latency + raw response to
  `HEALTHCHECKS_URL`, hits `/fail` on probe failure.
- `scripts/restore-postgres.sh` (executable): confirmation prompt,
  `DROP DATABASE IF EXISTS wlog; CREATE DATABASE wlog OWNER wlog`,
  `gunzip -c <file> | psql --single-transaction`.
