## What did not land (Phase -1 DoD gaps)

Two items from mandate §3.6 (Phase -1 DoD) are not fully met:

1. **"All CI workflows green on initial empty commit"**: workflows
   *configured* correctly but cannot *run* because GitHub Actions billing
   is blocked for the `wienerlabs` org since 2026-05-23. Every job today
   ends with the annotation:

   > The job was not started because recent account payments have failed
   > or your spending limit needs to be increased. Please check the
   > 'Billing & plans' section in your settings.

   This is a billing/payment problem, not a workflow problem. Workflow
   configuration was verified by running the equivalent commands locally:
   fmt, clippy, test, build all pass on the genesis commit.

2. **"Projects board configured with all milestones"**: `gh project create`
   requires the `project` OAuth scope which the active token lacks.
   Granting scope is a credential-modification action (mandate §10.1) so
   the build agent did not act unilaterally. Tracking issue: #11.

Additionally:

3. **Branch protection on `main`** could not be applied. Free-plan
   private repositories do not allow branch protection or rulesets:
   `HTTP 403: Upgrade to GitHub Pro or make this repository public`.
   Mandate-conflict surfaced explicitly in issue #9 with two viable
   options (public-flip ADR vs Pro upgrade) for human decision.

4. **Required signed commits** branch-protection rule deferred until the
   SSH signing key is registered on the GitHub account
   (`admin:ssh_signing_key` scope refresh required). Tracking issue: #10.
   Local SSH signing is configured and the genesis commit
   (`7f5c7d03d9c226e5cd83d035487286a973bf0e90`) carries a verified
   `ssh-ed25519` signature locally.

## Decisions made

- **Port choice for local Postgres: 5435** rather than 5432, to coexist
  with other Wiener Labs projects (rorschach uses 5433 per memory).
  Default credentials `wlog/wlog/wlog` because this stack is
  developer-local-only.
- **Clippy strictness: pedantic + all, no nursery.** Nursery lints
  ("missing_const_for_fn", etc.) too noisy for a scaffold. Pedantic +
  all is enforceable; nursery can be turned on per crate later.
- **Edition 2024, MSRV 1.95.0.** Matches the toolchain that was current
  when the project started. Pin in `rust-toolchain.toml` and `clippy.toml`.
- **No `core` PostgreSQL features.** sqlx with `runtime-tokio`,
  `tls-rustls`, `postgres`, `uuid`, `chrono`, `json`, `migrate`, `macros`.
- **Workspace resolver 3.** Required by edition 2024.
