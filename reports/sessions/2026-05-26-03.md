### Phase 1 ADRs

- **0005 LLM client**. Hand-rolled `reqwest`-backed `AnthropicClient`
  with explicit prompt caching, retries with jitter, and per-call
  `Usage` telemetry that flows into the cost ledger. Community Rust
  SDKs rejected; the API surface we need is small enough that
  controlling it ourselves is cheaper than tracking a third party's
  release cadence.
- **0006 prompt versioning**. File-per-version Tera templates
  (`synthesis_v1.tera`, `synthesis_v2.tera`, ...) selected via
  `wlog.toml`. Insta snapshot tests pin the rendered output for each
  fixture so silent edits fail CI. Provenance written to
  `tasks.prompt_provenance` JSONB so calibration can cut metrics by
  `(prompt_purpose, prompt_version, model)`.
- **0007 NATS subject hierarchy**. `wlog.{workspace}.event.{source}.{kind}`
  events, `wlog.{workspace}.command.{purpose}.{action}` commands,
  `wlog.{workspace}.result.{purpose}.{id}` results. Three JetStream
  streams (`WLOG_EVENTS` 30d/10GB file, `WLOG_COMMANDS` ephemeral
  memory, `WLOG_RESULTS` 7d file). Consumer naming
  `<crate>-<role>-<workspace>`. Envelope carries `schema_version` for
  forward compatibility.

### Ingest-git (Phase 1 #25, closed)

- `crates/wlog-ingest-git/src/lib.rs`: library API for hook lifecycle.
  - `install_all(repo, force)` writes `post-commit`, `post-merge`,
    `pre-push`.
  - `uninstall_all(repo)` removes only hooks that carry the
    `# wlog-managed hook v<version>` header. Foreign hooks survive.
  - `status(repo)` reports `installed`, `unchanged`, or `skipped` per
    hook.
  - `render_script(kind)` is the single source of truth for the hook
    body. The script calls `wlog hooks notify <kind>` in a
    `disown`-style background fork so the user's commit never waits on
    the daemon.
  - Honors `.wlog/no-track` at the script level for opt-out without
    uninstall.
- Three unit tests against a tempdir git repo cover install, idempotent
  re-install, and foreign-hook safety.
- `wlog hooks install|uninstall|status|notify` wired in `wlog-cli`.
  `notify` is a stub today; the socket and NATS publisher belong in
  Phase 1 #26.

## Decisions made

- **Hand-rolled Anthropic client** over a community SDK (ADR-0005);
  300-line `reqwest` surface beats a third party release cadence.
- **Numeric-version prompt files** over content-hash identifiers
  (ADR-0006); monotonic readability and clean calibration cuts.
- **Subject taxonomy** locks the workspace slug as the second segment;
  workspace renames now require an explicit migration.
- **Hook script body** stays minimal: a single line shells out to
  `wlog hooks notify` so logic lives in Rust, not bash.
- **clap_complete handler** moved off `Result<ExitCode>` after
  clippy's `unnecessary_wraps` lint flagged the gratuitous wrapping.
