## What landed

### ADRs

- **0002 Public repository flip and branch protection** (Accepted). The
  build agent cannot itself perform the flip (auto-mode tool gate enforces
  mandate §10.7); commented on #9 with the exact `gh` command for the human.
- **0003 Task DAG schema design** (Accepted). Single `tasks` table; enum
  `node_type` and `edge_type`; text `status` with CHECK; `vector(1536)`
  embedding column; `workspace_id` on every row; `ON DELETE CASCADE` from
  workspaces; no soft delete.
- **0004 Embedding model and dimensionality** (Accepted). OpenAI
  `text-embedding-3-small` at native 1536-dim. `EmbeddingProvider` trait
  abstracts the model so a future Voyage or `bge-m3` switch is one ADR
  away.
